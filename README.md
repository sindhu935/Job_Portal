# Job_Portal

A responsive Job Portal web application that allows users to browse, search, and apply for job opportunities. The project is designed with a clean user interface and smooth user experience to help users easily explore available jobs.

## Features
- Browse job listings
- Search and filter jobs
- Responsive design
- User-friendly interface
- Apply for jobs option
- Modern UI design

## Technologies Used
- HTML
- CSS
- JavaScript
